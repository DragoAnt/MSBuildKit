# DragoAnt.Samples.MinimalLibrary

A minimal sample library that shows a package built with DragoAnt.MSBuildKit.

## Getting started

```sh
dotnet add package DragoAnt.Samples.MinimalLibrary
```

## Usage

```csharp
var text = Greeter.Greet("Ada"); // "Hello, Ada!"
```
